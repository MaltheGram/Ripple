# Tips

- **Install dependencies** (Review "…" menu) once per project for go to definition into `node_modules`. Install scripts never run.
- Hover a **changed line** to see when the code it replaces last changed, by whom and in which MR.
- **Compare With Version…** (Review "…" menu) shows changes since any earlier push.
- Something slow? **View → Output → Ripple** shows timings for every step.

All settings are under **Ripple** in the Settings editor.
