# Comment and submit

Click the **+** in the diff gutter (select several lines first for a multi-line comment).

- **Add to Review** saves a **draft** only you can see; **Comment Now** posts immediately.
- Start with `nit:`, `q:`, `s:`, `b:` (blocking) or `p:` (praise) and it becomes a labelled comment: **nit:** …
- **`Alt+U`** jumps to the next unresolved thread; the **Comments** view lists them all.

When you're done, **Submit Review** (✈ in the Review toolbar) publishes all drafts, optionally approving.

Next time the author pushes, the Review list offers **"N files changed since your review"**, showing only the new changes.
